Organizing the bench — two rounds

Static HTML/CSS/JS concepts — everything is clickable and stateful, nothing is Blazor yet. All of them attack the same three problems: the vertical stack that wastes wide screens, the scattered chrome, and a 65-item nav you scan instead of search. The specimen, chips, controls, code and events are live in every concept.

Round 2 — refined for scale

After the round-1 verdict (A's instrument controls and grip, C's extensible modern shell, B breaks past ~10 parameters), every round-2 concept is stress-tested live: switch the component picker to MudDataGrid<Person> — 37 real parameters, and Dense, Striped, FixedHeader, Loading… actually re-render the specimen.

Concept D

L'Établi

The C × A synthesis. Mode shell (Play / Code / Present) with A's resizable instrument dock in Play — and the dock learns scale: parameter search, group chips, and a "Modified · n" filter that shows only what you touched.

signature — the searchable instrument dock Concept E

Palettes

Canvas first. The stage is the whole screen — a DataGrid finally breathes — while Parameters, Razor and Signals live in floating, draggable, collapsible dark palettes. Top-bar pills summon or dismiss each one.

signature — floating palettes over a full-bleed canvas Concept F

L'Inspecteur

Devtools for Blazor components. The scaffold graph is a selectable tree (MudDataGrid → Columns → PropertyColumn); picking a node shows its parameters, highlights its column in the specimen, and highlights its line in the razor. The composition-graph problem, answered in UX.

signature — scaffold tree → specimen highlight

Round 1 — first exploration

Concept A

La Console

Instrument cockpit. The stage owns the screen; Parameters, Code and Events live in a resizable bottom dock; parameters become a horizontal bank of instrument cells. Icon rail + ⌘K palette replace the sidebar.

signature — the control-surface dock Concept B

La Fiche technique

The component as an electronic part. Framed specimen with live width measurement, a Characteristics table, code as the reference circuit, events as the signal log. Hover a parameter row: a leader line points at the part.

signature — leader lines row → specimen Concept C

Le Studio

Organization by task. One shell, three modes: Play (stage + controls), Code (editor in majesty — the v2 teaser), Present (full-bleed dark demo reel with auto-advancing examples). The grid morphs between them.

signature — mode morphing + filmstrip

The three share the validated identity — violet #6D4AFF, mono as the API voice, dot-grid stage — so any of them (or a blend) can be implemented in the real shell without a rebrand.
