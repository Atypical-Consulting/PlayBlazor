## Overview
PlayBlazor is a "Storybook for Blazor": auto-generated component playgrounds driven by reflection over `[Parameter]` properties — no story files. This handoff covers the validated workspace shell (Concept G v2): a mini visual IDE with four dockable panels (Graph, Parameters, Razor, Signals) around a specimen stage, plus a Present mode for demos.

## About the Design Files
`concept-g-ide-v2.html` is a **design reference created in HTML** — a self-contained prototype showing intended look and behavior, not production code. The task is to **recreate this design in the PlayBlazor host app** (Blazor, inside the MudBlazor fork — design docs live under `docs/superpowers/design/2026-08-28-playblazor-ux-concepts/`). Real data replaces the mock: the component list comes from reflection, the specimen is the real rendered component, Razor is generated by the real generator (omit-defaults rule), Signals subscribes to real `EventCallback`s.

## Fidelity
**High-fidelity.** Colors, typography, spacing, radii and interactions are final. Recreate pixel-perfectly; keep MudBlazor's own theme inside the specimen so chrome never competes with the component.

- Semantic: wired-event green `#14996A`; specimen uses MudBlazor palette (`#594AE2` primary…)
- Fonts: monospace = API voice (`ui-monospace, "Cascadia Code", "SF Mono", Menlo, Consolas`) for parameter names, snippets, chrome labels; system sans for prose. Sizes: chrome labels 10–12px, param rows 11.5px, code 12px/1.75
- Radii: panels 12px, stage 14px, controls 6–8px, pills/chips 999px. Focus: 2px accent outline, 2px offset. `prefers-reduced-motion` kills all transitions/animations

## Layout
- Chrome bar 48px: wordmark `▶ PlayBlazor`, component picker (mono select), 4 panel pills, centered Play/Present segmented control, right `Reset layout` + accent `Share ⤴`
- Workspace CSS grid, 10px gaps/padding: areas `"stage right" / "bottom right"`; right dock 330px default (240–560, grip resize), bottom dock 235px default (120–520)
- Zones hide entirely when all their panels are closed/floated; grid collapses to give the stage the space
- Stage: dot grid, presets chips top-left (`Examples` label + chips), specimen centered, caption bottom-left `‹Component /› · scaffolded by the host · MudBlazor 8.x`
- Under 860px: single column (stage / right / bottom stacked), grips and drag disabled

## Panels — shared chrome
Header (grab cursor): `⠿` grip, uppercase mono title, badge pill, actions right (`⧉` copy on Razor, `⌫` clear on Signals, `▾/▸` collapse, `✕` close). Body scrolls. Behaviors:
- **Drag to dock/float**: dragging a header >5px lifts the panel into a floating palette (shadow `0 22px 55px -18px rgba(20,20,35,.5)`, width 350); both docks show dashed accent drop targets, hot state within 20px; drop position inserts before/after siblings by pointer vs their centers; drop elsewhere floats it
- **Float extras**: resizable from right edge, bottom edge, and corner (min 250×130, max 760×80vh); positions/sizes persisted; re-clamped into the viewport on load and window resize; **double-click header re-docks** to its default zone
- **Persistence**: whole layout in `localStorage` (`pb-g-layout-v2`); `Reset layout` restores defaults (right: Graph+Parameters, bottom: Razor+Signals)
- **Pills / keyboard**: pills toggle each panel; keys `1–4` do the same; `/` focuses the parameter filter (reopening the panel if needed)

## Panels — content
- **Graph** (badge `scaffold`): the host scaffold tree as tag-styled nodes (`<MudDataGrid T="Person">` → `<Columns>` → 3 `<PropertyColumn …>`), indent 0.85rem/level. Selecting a node re-scopes Parameters, highlights the matching razor lines, and highlights the column in the specimen (`rgba(109,74,255,.14)` + 2px accent underline). `↑↓` walk, Enter selects. Hint line explains the metaphor
- **Parameters** (badge = selected node): toolbar = filter input with `/` kbd hint, `Modified · n/total` chip (click = filter to modified), `⊟/⊞` fold-all, `↺` reset node to defaults (toast). Grouped `<details>` (Appearance, Behavior, Filtering…) with uppercase summaries + hairline. Rows: mono name (violet `●` when modified; `title` tooltip shows the C# signature, e.g. `[Parameter] public bool Dense { get; set; } = false;`) + control right: segmented (enums ≤3), select (enums >3), 32×17 toggle, number/string inputs, `◇` badge for slots/data, `⚡ wired` for events
- **Razor** (badge `generated`): syntax-tinted generated snippet, omit-defaults; selected node's lines get accent tint + 2px left bar; `⧉` copies plain text + toast `Razor copied ✓`
- **Signals** (badge = count): every EventCallback logs `time · name · short args`; entries with detail unfold on click (`▸` rotates) to a pre-formatted args block; capped at 50; `⌫` clears; count resets on component switch. Empty state: "Actuate the specimen — every EventCallback lands here."

## Specimen wiring (must be real in production)
- All parameter edits re-render live; example chips seed whole parameter sets
- MudButton: `OnClick` logs `MouseEventArgs`
- MudDataGrid: row click logs `RowClick` (`DataGridRowClickEventArgs<Person>` detail); with `MultiSelection`, checkboxes highlight rows (`rgba(109,74,255,.08)`) and log `SelectedItemChanged`; header checkbox selects all and logs `SelectedItemsChanged`; `SelectOnRowClick` makes row clicks toggle selection; checkbox clicks don't bubble into `RowClick`
- Per-column params scope to their tree node: `Title`/`Hidden` change the rendered column; `Sortable`/`Filterable`/`Resizable` gate the header glyphs (`↑`, `⧩`, resize edge mark) that the grid-level `SortMode`/`Filterable`/`ColumnResizeMode` enable

## Present mode
Stage goes full-bleed dark, specimen scales 1.25, all chrome/panels hidden. Bottom HUD pill: component name, preset filmstrip, `❚❚/▶` autoplay control, `esc to exit`. Autoplay cycles presets every 4s with a 2px progress underline on the active chip (animation only while autoplaying); any manual pick (chip or `←/→`) pauses; `▶` resumes from the next preset. Disabled under reduced-motion.

## Feedback
Toast: mono pill, top-center under the chrome bar, 1.6s (`Razor copied ✓`, `Link copied ✓`, `Node parameters reset ✓`). Share copies the current URL — in production it should encode component + parameter state.
